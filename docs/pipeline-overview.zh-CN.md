# 核心 Pipeline 说明

DataMagic 采用从数据到视频的分阶段流程，将数据理解、规格生成、场景生成、视频编排和交互编辑拆开处理。本文只提供产品级实现概览，不公开内部源码或完整提示词。

## 核心流程

1. **用户输入**
   用户上传或粘贴表格数据，并描述希望生成的可视化目标。

2. **数据理解**
   系统分析字段类型，识别数值列、时间列、分类列，并总结候选洞察。

3. **DVSpec 规划**
   AI 规划器生成声明式数据视频规格，包含场景、图表意图、旁白、时间节奏和数据绑定。

4. **场景生成**
   系统根据 DVSpec 和视觉模板生成候选动画场景。

5. **视频编排**
   将多个场景按照叙事节奏组织成完整时间线，并与旁白时长对齐。

6. **运行时预览**
   浏览器端实时预览生成结果，并支持直接视觉编辑。

7. **自然语言修改**
   用户可以继续提出修改需求，例如更换图表类型、修改文案、调整颜色或布局。

## 产品模式

- **Full Video：** 生成多场景、带旁白的完整数据视频。
- **Single Chart：** 从粘贴或上传的数据快速生成单个动态图表。
