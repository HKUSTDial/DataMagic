# 帮助中心

这份指南说明 DataMagic 是什么、应该选择哪种生成模式、如何准备数据、如何写需求、如何编辑生成结果，以及遇到问题时如何排查。

## DataMagic 是什么？

DataMagic 是一个 AI 数据视频系统，可以把结构化数据转化为带旁白的动态视频，也可以快速生成单个动态图表，并且支持在浏览器中继续编辑。

## 应该选择哪种模式？

**完整视频**

当你想生成一个多场景、带旁白、适合汇报的数据故事时，选择完整视频。它适合分析报告、业务复盘、研究总结和数据叙事。

**单个图表**

当你已经知道数据结论，只需要一个动态图表时，选择单个图表。它更快，适合快速沟通、仪表盘素材和已经完成分析的场景。

## 数据要求

- 使用 CSV 文件或粘贴表格，并确保第一行是清晰的列名。
- 每列只表达一个概念，例如日期、产品、收入、成本、地区或类别。
- 图表通常需要至少一个数值列。
- 如果要生成趋势图，请包含稳定的时间列，例如日期、月份、季度或年份。
- 避免合并单元格、空表头、说明文字混在数据行中，或过深的 JSON 结构。

## 如何写好需求？

好的需求应该说明观众需要理解的洞察、对比、趋势或排名。

示例：

```text
对比每月收入，并突出增长最强的月份。
```

```text
展示各产品收入占比，并强调最大类别。
```

```text
解释客户流失率按季度的变化，并指出风险最高的时期。
```

尽量避免过于模糊的需求，例如：

```text
做得好看一点。
```

## 如何编辑生成结果？

生成后可以继续微调，不一定要从头重新生成。

- 在预览中双击可编辑文字，可以直接修改标题、标签和简短说明。
- 在支持的图表上，可以调整颜色、强调样式和部分布局。
- 使用 AI 编辑面板提出自然语言修改，例如“改成深色风格”或“把副标题写得更简洁”。

## 积分和生成时间

生成会消耗积分，因为 DataMagic 需要运行 AI 分析、场景生成、旁白对齐和渲染校验。

- 完整视频消耗更多，因为它会生成多场景视频。
- 单个图表更快，消耗积分更少。
- 生成耗时会受到数据复杂度、模型响应速度和渲染校验影响。

## 常见问题

### 系统提示数据无法分析怎么办？

请检查第一行是否是列名，表格是否至少包含一个数值列，并确认数据没有为空或混入大量说明文字。

### 生成的图表不是我想要的怎么办？

可以把需求写得更具体，生成前选择偏好的视觉风格，或者在编辑面板里要求更换图表类型。

### 预览画面异常或某个场景渲染失败怎么办？

可以先刷新预览。如果问题仍然存在，在可用时使用视觉修复，或者用更明确的需求重新生成。

### 可以导出生成的视频吗？

视频生成完成后，在预览页使用导出功能。导出能力可能会受到当前部署配置影响。
