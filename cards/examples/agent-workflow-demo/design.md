# 操作演示 v2：从配方到可修改的视频

## 制作基准

用户授权自主制作；目标是让创作者看懂「挑选 → 复制 → 附数据提出任务 → 渲染 → 自然语言修改 → 交付」。旧版 76 秒教程保留。

线上使用真实公开配方库，数据为虚构咖啡店的 36 个销量数值。独立 Codex CLI 尝试因认证 401 失败，本片不声称成功使用独立 CLI：后续由当前助手生成参数并实际渲染。交互段是本次真实请求/执行记录的可视化重排，持续标明「流程演示 · 非客户端录屏」，不绘制或冒充 Codex 原生 UI，不展示终端原始私密日志。

## 视觉决策

选择「清晰的产品操作演示」，不选择广告式猛烈剪辑。提取 gallery/styles.css：背景 #f7f8fb，白色表面，文字 #171b25，强调蓝 #3568e8，辅助灰 #697184，Inter + Noto Sans SC，圆角 16–24，8px 间距网格。保持平面阅读；品牌片头允许轻微景深层次，不使用抖动、满屏闪白或透视压缩文字。

沿用已确认的 DataMagic 品牌规范和已有宣传片，跳过独立 styleframe；每镜头先做静帧预检。旁白主导节奏而非强鼓点卡拍：因此不采用 skill 的强 tech-house 建议（S1），以已有程序生成轻配乐托底，关键点击提供短促拟音。工作台与剪映交付按用户之前的暂停要求不做。工作树已有大量未提交工作，不为每镜头创建 git commit。

## 镜头映射

- 真实页面采集：Video ShotCraft PageCam 方法，2x 纹理与元素坐标；采用稳定推近，不强加倾斜。
- 复制按钮：input-trigger-moves / cursor-performance；已核对 gallery/api/library.json 与 CursorPerformancePunchIn.tsx。保留 24f 过冲 1.05 + 6f 回落、click=40、推近 40–52f 至 1.4、停到 72f、90f 回正、独立涟漪消散与条件卸载；调整坐标匹配真实按钮。
- 输入与结果：自制中性的「流程演示」面板，不复刻第三方界面。输入逐字出现，附件先进入，执行节点依实际命令和结果分阶段展开；这是叙事重排，不是实际墙钟速度。
- 成片与修改：真实新渲染 MP4；第一版摘录，新版完整 14 秒，结尾显示可交付文件。
- 对象识别：六种饮品使用独立 SVG 图标；图标随对象 ID 移动。修改版保留六种配色，拿铁使用紫色描边与高亮，其他柱子以 0.72 透明度淡化。
- 参考能量骨架 promo-energy-arc；教程用途不做全片最高能量的爆炸收尾（Q8），改为结果、文件、入口的稳定收束。

## 唯一时间线（30 fps）

| 镜头 | 秒 | 内容 | 验收帧（全局） |
| --- | --- | --- | --- |
| result | 0–4 | 新版效果引入，品牌点题 | 30, 90 |
| gallery | 4–14 | 真实库录屏：搜索、选择、打开详情 | 150, 360 |
| copy | 14–19 | 真实详情截图、光标点复制的镜头包装 | 450, 480, 520 |
| prompt | 19–29 | 数据附件与用户任务输入 | 630, 810 |
| execute | 29–35 | 实际数据校验、渲染与产物记录 | 900, 1020 |
| first | 35–43 | 第一版实际视频摘录（2–10秒） | 1080, 1230 |
| revise | 43–51 | 修改指令输入，关键要求浮现 | 1320, 1500 |
| final | 51–65 | 新版完整 14 秒；结尾停两秒 | 1560, 1920 |
| deliver | 65–72 | MP4 / CSV / JSON 与公开入口 | 1980, 2130 |

字幕单行 56px 以上，辅助信息至少 32px。配方原始 UI 和成片中的小字号作为真实素材保留，不声称在手机上能逐字阅读；将本镜头必须读到的操作与结论另用大字表达。所有时间与 SFX 以这份分镜派生；两版音频交付共用同一画面时间线。
