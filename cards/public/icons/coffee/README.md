# Coffee icons

Six original SVG illustrations for the DataMagic coffee-sales example: americano, latte, cappuccino, mocha, tea, and cold brew. Each illustration uses a 128×128 viewBox and stays recognizable at a small display size. These depict drink categories, rather than brand marks.

Supply an entity's `iconSrc` as `icons/coffee/latte.svg`, or replace it with your own local image under `public/`. The bar chart race keeps the image, label, and color attached to the entity ID as the rank changes.

六个图标为本项目绘制，可修改 SVG 的颜色与形状，沿用项目许可证。
